# Sonar — docs

**このディレクトリだけを読めば、プロジェクトの全体像と「次に何をすべきか」が分かる。**

Sonar は、アイスブレークから自分の信念や大切にしたい感情まで降りていく対話アプリ。
AI は次の問いを1つ出すだけで、**結論を言うのは常に本人**。分岐の軌跡がマインドマップとして残る。
コードはこのリポジトリ（`~/workspace/sonar`）、判断と設計の正典は Obsidian Vault にある。

---

> **【重要】`docs/` はすべて生成物。ここを直しても次の生成で消える。**
>
> 正典は Windows 側の Obsidian Vault `01_projects/06_sonar/` にあり、生成は Vault の
> `python3 tools/build_docs.py` が行う（方向は **Vault → このリポジトリの一方向**）。
> 実装中に気づいたこと（逸脱・罠・判断）は `docs/` に書かず、**セッションの出力として報告する。**
> Vault 側の `詳細設計書` / `次の作業の入口` に反映され、再生成でここへ降りてくる。
>
> 根拠：ADR-0005 §3-3（コードとドキュメントは提出物⑦の要件から別リポジトリ）と
> §3-4（`mock/` と同じ一方向コピー）。**リポジトリの統合ではない**ので §8 の蒸し返し禁止には触れない。

生成日時：**2026-08-31 21:18**（この日時が古いと感じたら、Vault 側で再生成してから読む）
