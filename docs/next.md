## 3. 踏むと分かっている罠

**すべて実測済み。同じ時間を二度払わない。**

| 罠 | 症状 | 対処 |
|---|---|---|
| **`topcoat dev` がアセット単体の変更を拾わない** | `.js` / `.css` を直しても古いものが配られ続ける。200 が返るので**コードの間違いと見分けられない** | **dev サーバを再起動する。** 配信URLのハッシュが変わったかで切り分ける（→[ADR-0005 開発環境](adr/0005-dev-env.md) §3-7） |
| **`view!` は値なしブール属性を通さない** | `<button hidden>` がコンパイルエラー | `hidden=(true)` と書く。属性値は**文字列リテラルか `(式)`** のどちらか |
| **`push_schema()` はマイグレーションではない** | 2回目の起動で `table already exists` | 接続**前に**ファイルの有無を見る（→[設計書 データベース](design/database.md) §10） |
| **Anthropic は短い出力を2〜3デルタにしか刻まない** | 「1文字 → 残り全部」でちらつく | `typeOut()` に一定速度で描かせる（→下記） |
| **ポート3000は `yse_compass` が占有** | `AddrInUse`。または**Next.js の応答を200と誤読する** | `PORT=3100`。**本文まで見る**（→[ADR-0005 開発環境](adr/0005-dev-env.md) §3-7） |
| **zsh の `=` 展開** | `cargo install --version =0.7.0` が失敗 | クォートする（`'=0.7.0'`） |

> **【注意】`typeOut()` の改造がいちばん間違えやすい**
> 現在の `typeOut(text, done)` は **全文を受け取って** `questionEl.textContent = ""` で始める。
> SSE では文字列が**継ぎ足される**ので、そのまま呼ぶと**デルタが来るたびに表示がリセットされる**。
>
> **直し方**：受け取った文字をキューに積み、描画ループは一定速度で回し続ける。
> 中断（`stopTyping`）は `EventSource.close()` と対にする（→[設計書 プロンプト](design/prompt.md) §12）。
