## これは何か

### モックで確定した設計判断（`mock/README.md` が正典）

1. チャットアプリに見せない（相槌が無いUIを吹き出し往復で作ると尋問に見える）
2. 傾聴は相槌ではなく「直前の発話を織り込んだ問い」で示す
3. 入口は「気分をタップ1回」——最初の問いを選択式に置き換える
4. 深さはユーザーが決める（段数を表示しない・途中でやめても失敗にしない）
5. 地図に残るのは本人の言葉だけ（答えた分だけ点が置かれる）
6. **別々の会話のノードは合流させない**（→[ADR-0003 地図のデータ構造とレイアウト](adr/0003-map-data.md)）
7. 縦軸＝根からの距離。**カテゴリ名も段数の上限も置かない**（対話画面の背景も同じ連続量。2026-08-30 統一）
8. **全体表示は会話単位で畳む**（1画面の点の数が会話数で決まる）
9. 大きさは画面px基準、位置だけが世界座標（倍率によらず当たり判定48px・ラベル13px）
10. 地図は画面いっぱい。点を押すとズーム。パンとホイール拡大に対応
11. ラベルは寄り具合で出し分ける（意味的ズーム）。**全体表示では出さない**（触れた点と根だけ。2026-08-30 修正）
12. 前後移動は「開いている会話の中」だけ。戻るのも一段ずつ
13. ライト／ダークは本人が選ぶ。「深さ＝暗さ」は相対的な水深ランプとして両モードで成立

### コード側の `docs/`（WSL。2026-08-31 追加）

コードは WSL、ドキュメントは Vault に分かれているため（→[ADR-0005 開発環境](adr/0005-dev-env.md) §3-3）、**WSL 側の Claude Code はこのノート群を見に行けない。** そこで `mock/` と同じ一方向コピーで、参照用の写しを `~/workspace/sonar/docs/` へ生成する。

```bash
python3 tools/build_docs.py
```

**参照が壊れていないかは `python3 tools/check_links.py` が見る**（2026-09-01 追加）。
リンク切れ・ビルドの出典の実在・**このハブに載っていないノート**の3つ。**規律ではなく機械で守る**ための3本目の道具。

**正典は Vault のまま。`docs/` は生成物で、手編集はハッシュ照合で止まる**（`tools/.docs.sha256`）。決定と収録範囲は [ADR-0005 開発環境](adr/0005-dev-env.md) §3-8 が持つ。**リポジトリの統合ではない**ので §8 の蒸し返し禁止には触れない。
